# MNX DNS

High-performance, clean, and private DNS manager for Windows, Mac, and Linux.

## Features

- Switch DNS servers instantly with one click
- Browse and explore curated DNS server list
- Benchmark DNS latency to find the fastest server
- Flush DNS cache
- Custom DNS server support
- Auto-launch on startup
- Minimize to system tray
- Dark/light theme support
- Multi-language (English, Farsi, Russian)
