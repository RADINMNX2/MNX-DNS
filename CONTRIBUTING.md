## Folder Structure

- [UI (Renderer)](./src/renderer)
- [Main Process](./src/main)

## Getting Started

1. Fork and clone the repo
2. `npm install`
3. `npm run dev`
4. Make your changes
5. Commit and open a Pull Request

## Code Style

- TypeScript strict mode
- React functional components
- Tailwind CSS for styling
